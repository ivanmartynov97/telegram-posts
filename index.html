Настройки
GitHub токен
Нужен для редактирования и удаления постов.
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Contents: Read & Write для репо telegram-posts.
Bot Token
Токен бота-администратора канала. Нужен для показа числа подписчиков и статистики.
Второй канал
Тот же GitHub-токен и бот-токен работают для обоих каналов — отдельные нужны только если используешь разные репозитории. Посты/идеи/статистика хранятся в отдельных папках, темы между каналами не пересекаются.
